# 开头简介

老牌经典油猴脚本 SearchEngineJump 经我现代化改造

升级为 SearchEngineJump++, 界面更现代，功能更强大;


"划词搜索"功能史诗级加强, 已经可以彻底替代各种划词搜索类浏览器插件

包括但不限于: Chrome 的 Selection Search, 火狐 Swift Selection Search 等等;


更添加了 "右键搜图" 功能, 取代了各种右键搜图类浏览器插件, Search by Image 等等;


一个脚本取代多个插件, 顺便解决有些插件只有 Chrome 版或 Firefox 版的问题, 让你在不同浏览器间切换时不再需要重新安装插件;

还有更多实用功能等你体验;
